# Gerador de QR Code para E-commerce

Este projeto e um gerador de QR Codes personalizado para e-commerces utilizando Node.js, executado diretamente no terminal.

## Funcionalidades
- Gerar QR Codes para links de produtos ou lojas.
- Escolha entre tamanho compacto ou normal.
- Interface simples via terminal.

## Como usar
1. Navegue ate a pasta do projeto.
2. Instale as dependencias:
   ```bash
   npm install
   ```
3. Execute o comando:
   ```bash
   npm start
   ```

## Estrutura
- `src/prompts`: Configuracao das entradas do usuario.
- `src/services`: Logica de geracao do QR Code.
- `src/index.js`: Ponto de entrada do sistema.
